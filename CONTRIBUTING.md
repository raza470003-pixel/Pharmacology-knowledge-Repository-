# Contributing

## Ground rules
- Follow [Evidence-Methodology.md](10-References-and-Evidence/Evidence-Methodology.md).
- Write in your own words; do not paste textbook or website text.
- Never add a reference you have not opened. No invented DOIs.
- No patient-specific advice.

## How to contribute
- **Drug profile:** copy `12-Templates/Drug-Profile-Template.md` into `08-Individual-Drug-Profiles/<Letter>/`.
- **Classification:** edit the relevant folder in `02-Drug-Classification/`.
- **Interaction record:** use `Drug-Interaction-Template.md`; severity must come from a cited source.
- **Comparison table:** use `Drug-Comparison-Template.md`.
- **Scientific error:** open a "Scientific correction" issue with a source.

## Pull requests
One topic per PR, templates followed, references listed, Mermaid and links checked, and the PR checklist completed.
