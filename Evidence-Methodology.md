# Evidence Methodology

1. Never fabricate references, DOIs, interactions or indications.
2. Separate established facts from emerging evidence.
3. Cite important claims next to where they appear.
4. Write original explanations; do not copy textbook text.
5. Label off-label uses clearly.
6. Name the jurisdiction when recommendations differ.
7. Prefer current official safety information.
8. State limitations of the evidence.
9. Give no patient-specific treatment advice.
10. Interaction severity must follow a cited source, never personal judgement.
11. Claim an audit only when it has actually been done.
